# Fit Evolution — Gotham V6.5

Finitions graphiques : amélioration des contrastes, boutons de formulaire, contrôles de difficulté, curseurs, tableaux et adaptation mobile. Axe des dates du graphique de poids simplifié. Progression affichée également en pourcentage exact.

## Installation
Extraire dans un nouveau dossier. Conserver votre ancienne installation en sauvegarde. Copier vos données personnelles (base SQLite, configuration d’accès, musique) depuis l’ancienne version uniquement après avoir effectué une sauvegarde.

## Important
Cette livraison ne contient pas encore le mannequin interactif. Aucun test complet dans un navigateur Streamlit n’a été réalisé.
