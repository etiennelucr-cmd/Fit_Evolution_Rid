# Fit Evolution V6.3 — Coach articulé

- Animations SVG articulées avec positions distinctes : squats, pompes, fentes, burpees, mountain climbers, gainage, jumping jacks, course, crunch.
- Chronomètre basé sur performance.now(), préparation de 3 secondes, effort et repos automatiques, pause/reprise.
- Test vocal français via synthèse du navigateur et indication d’erreur ; les voix dépendent de Windows/iOS et ne sont pas garanties.
- Modes Programme original, Circuit dynamique et Challenge avancé conservés.
- Les animations sont schématiques, ne corrigent pas la posture.

## Installation
Décompresser dans un dossier neuf. Copier depuis votre installation actuelle `fit_evolution.db`, `acces_local.json` et `ma_musique/` si vous souhaitez retrouver vos données. Ces éléments privés ne sont PAS inclus dans le ZIP. Lancer `Lancer_Fit_Evolution_Reseau.bat`. Sur iPhone, même Wi-Fi que le PC, puis actualiser Safari.

## Limites
Le coach vocal utilise encore la synthèse vocale locale du navigateur : si aucune voix ne se déclenche, vérifier les voix installées et la lecture audio. La V6.3 n’inclut pas d’enregistrements audio parlés. Test réel Windows/iPhone non effectué.
