# Fit Evolution V6.2 — Challenge

Nouveau dans Séance guidée : choix Programme original, Circuit dynamique ou Challenge avancé. Paramètres effort, repos, tours et feedback RPE de 0 à 10, avec suggestions de progression prudente. Les annonces vocales et le minuteur de la V6.1 sont conservés. Les tours sont organisés par exercice dans le coach.

**Installation** : décompresser dans un nouveau dossier. Copier vos fichiers `fit_evolution.db`, `acces_local.json` et le dossier `ma_musique` depuis votre installation actuelle, sans écraser les scripts. Lancer `Lancer_Fit_Evolution_Reseau.bat`.

La perte de poids visée (1 kg/semaine ou autre) ne pilote pas l’intensité des exercices. Arrêter en cas de douleur, vertiges ou malaise. Éviter le challenge les jours de fatigue/courbatures importantes. Les animations sont illustratives. Le feedback de challenge est enregistré dans les préférences locales, pas automatiquement comme séance terminée : utiliser le formulaire de séance.

**Validation** : compilation Python et intégrité ZIP. Tests interactifs sur Windows/iPhone à effectuer sur les appareils.
