# Fit Evolution V6.3.1 — Correctif macronutriments

- Les produits Open Food Facts enregistrent automatiquement les protéines, glucides et lipides lorsque les trois valeurs sont disponibles.
- Les macros sont affichées sur la fiche du produit.
- Le journal permet de compléter les macros des aliments déjà enregistrés.
- La saisie manuelle distingue les valeurs inconnues des vraies valeurs à zéro.
- Les aliments fréquents réutilisent les dernières macros connues pour un aliment et une portion identiques.
- Le bilan de progression et les graphiques réutilisent les données stockées.

**Attention :** les aliments déjà enregistrés sans macros ne sont pas devinés. Complète-les dans le journal. Les données Open Food Facts peuvent être absentes ou imprécises.

Installation : sauvegarde tes données `fit_evolution.db`, `acces_local.json` et `ma_musique/`, puis copie-les dans le nouveau dossier. N'envoie jamais tes données personnelles dans le ZIP distribué.
