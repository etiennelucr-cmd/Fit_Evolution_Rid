# Fit Evolution V6.4 — Gotham 1989 / finitions visuelles

Cette version améliore le thème : navigation active dorée, contrastes, cartes, champs, boutons, tableaux, panneaux, accordéons, barre de progression et affichage mobile.

## Installation
1. Ferme Fit Evolution.
2. Sauvegarde ton dossier précédent.
3. Décompresse cette archive dans un nouveau dossier.
4. **Recopie depuis ton ancienne version** `fit_evolution.db`, `acces_local.json` et le contenu de `ma_musique/` dans ce nouveau dossier.
5. Lance `Lancer_Fit_Evolution.bat`.

**Important :** les données personnelles et les identifiants ne sont pas inclus dans l'archive livrée. Les modules métier sont conservés. La refonte du mannequin interactif n'est pas incluse dans cette livraison.
